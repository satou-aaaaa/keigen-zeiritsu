# 軽減税率どっち

品物や場面（イートインと持ち帰り・屋台・宅配ピザ・ノンアルコールビール・おまけ付きのお菓子・送料・新聞など）から、かかる消費税が軽減税率（飲食料品）か標準税率（10%）かを当てる学習ゲーム。だれでも同じ1日5問。

- 遊ぶ: <https://satou-aaaaa.github.io/keigen-zeiritsu/>
- 場面が出ます。札（軽減税率・標準税率・消費税はかからない・品物ごとに分ける）から1つ選びます。
- 正しく選ぶと「なぜそうなるか」と国税庁の Q&A の問の番号・出典が出て、税率帳に集まります（8種類）。
- ★はまちがい＋ヒントの数で決まります（0で★3）。時間の制限はありません。
- 今日の5問と上級（3問・ヒントなし・札4枚）は1日1回。とことんは何度でも、「ここでやめる」まで続きます。遊べなかった日は7日前まで、カレンダーから「あとから」遊べます。
- 答えと説明は、国税庁「消費税の軽減税率制度に関するQ&A（個別事例編）」（令和8年4月改訂）に沿っています（2026年11月に確かめた内容）。<https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/qa_03.htm>
  - 飲食料品の範囲・容器・送料（問1〜41）、外食・ケータリング（問49〜83）、一体資産（問84〜96）、新聞（問97〜102）。
- 飲食料品の軽減税率はいまは8%です。令和9年4月1日から2年間は1%に下げる予定です（法案が成立した場合。対象の範囲は今の8%と同じ）。国税庁「飲食料品の消費税率の引下げ」<https://www.nta.go.jp/taxes/shiraberu/zeimokubetsu/shohi/keigenzeiritsu/zeiritsuhikisage.htm>。このため札は税率の数字でなく「軽減税率」「標準税率」で答えます。
- 税の相談ではありません。実際の取引は、国税庁の資料や税務署・税理士に確かめてください。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、Google に IP アドレスが届きます。「X」「LINE」「コピー」を押したときだけ、結果の四角が選んだ先に渡ります（答えは入りません）。
